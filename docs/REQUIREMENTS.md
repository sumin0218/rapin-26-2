# RAP-IN 26-2 정기공연 페이지 요구사항

> 상태: 초안 (2026-11-21). 포스터와 디자인이 정해지면 화면 구성은 다시 정해요.

## 1. 목적과 대상

- **목적:** 공연 전 홍보. 인스타그램, 카카오톡으로 링크를 공유해서 공연을 알리고 관객을 모아요.
- **대상:** 불특정 외부인 (교내외 관객). 내부 정보는 넣지 않아요.
- **주 사용 환경:** 휴대폰 (SNS 앱 안의 브라우저 포함). PC도 지원해요.
- **범위 밖:** 공연 당일 기능 (NOW/NEXT, 실시간 갱신), 방명록, 서버나 DB가 필요한 기능.

## 2. 페이지 구성

| 순서 | 섹션 | 내용 |
|---|---|---|

## 3. 기능 요구사항

### 필수

- **모션 포스터**
  - 처음 들어오면 등장 연출.
  - 가만히 있어도 레이어가 은은하게 흔들리는 반복 모션.
  - 스크롤하는 동안 화면을 고정하고 스크롤 양에 맞춰 장면이 진행 (pin + scrub). 고정 구간은 화면 2~3배 이내.
  - 공연명, 날짜, 장소 같은 글자는 이미지가 아닌 실제 텍스트.
- **공연 정보:** 일시, 장소, 입장 방법, 지도 링크 (네이버 지도, 카카오맵).
- **순서표**
  - 정기공연은 **2부 구성**.
  - 곡마다 곡 제목, 아티스트 활동명, 프로듀서/피처링 크레딧.
  - **미리듣기 15~30초.** 전체 음원은 넣지 않아요. 한 번에 한 곡만 재생.
- **언어:** 한국어, English, 中文. 브라우저 언어로 자동 선택하고 버튼으로 바꿀 수 있음.
- **공유 미리보기:** 카카오톡, 인스타그램에 링크를 붙이면 포스터 이미지와 제목이 뜸 (og 태그).

### 선택 (여유 있으면)

- 아티스트 페이지에서 그 아티스트의 곡 미리듣기.
- 캘린더에 추가 버튼 (.ics 파일).
- 공연까지 남은 날짜 표시 (D-n).

## 4. 비기능 요구사항

- **성능:** 휴대폰 LTE에서 첫 화면 3초 안에 표시. 첫 화면에 필요한 것만 먼저 불러오고 미리듣기 음원과 아티스트 사진은 필요할 때 불러오기.
- **접근성**
  - 애니메이션 줄이기 설정이면 모션 없이 정지 포스터.
  - 키보드로 모든 버튼 사용 가능.
  - 이미지에 대체 텍스트, 충분한 글자 대비.
- **호환성:** iOS Safari, Android Chrome, 카카오톡/인스타그램 앱 안 브라우저, PC Chrome/Edge/Safari 최신 버전.
- **호스팅:** GitHub Pages (`sumin0218/rapin-26-2`). 빌드 과정 없는 정적 사이트.
- **관리:** 공연 정보, 순서표, 아티스트, 문구는 `data/` JSON만 고치면 반영. 코드를 몰라도 수정 가능하게.

## 5. 공개 콘텐츠 원칙

- 아티스트 이름은 **본인 동의를 받은 활동명**만.
- 미리듣기는 15~30초. 미발매곡이나 샘플이 들어간 곡은 담당자와 확인 후 공개.
- 내부 자료 (임원진 피드백, 리허설 영상, 전체 음원)는 넣지 않기.
- 포스터 글꼴, 사진의 웹 사용 권한 확인.
